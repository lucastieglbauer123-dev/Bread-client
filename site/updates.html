Update log

What changed.

A short, honest record of changes to the launcher and the site. The release page remains the source for installers and checksums.

Last updated 1 October 2026

1 October 2026

Clearer project site

  • Moved the public site to its own Cloudflare Pages address.
  • Moved the detailed change history off the home page and into this update log.
  • Added direct support links for the Bread Client community, the Minecraft server, and private bug reports.

30 September 2026

Less friction, clearer control

  • Content tabs keep Mods, Resource Packs, Shaders, and Datapacks selectable even when one category is empty.
  • Expired Minecraft tokens are no longer passed into Java after a refresh outage.
  • Added a local Offline workspace switch for managing local files without starting sign-in or browse actions.
  • System theme changes are picked up when the app returns to the foreground, and custom Bread themes stay local.

27 September 2026

A smoother instance workspace

  • Fixed instance tabs so Mods, Resource Packs, Shaders, and Datapacks open the matching view.
  • Logs keep receiving new lines while you move between instance tabs, and the selected crash log stays open when you return.
  • Added the deep black HarI theme and the navy stopswamp theme.
  • Updated the Minecraft title artwork to a centred Bread mark that leaves the Java Edition sign clear.
